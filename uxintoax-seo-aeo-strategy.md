## Phase 7: AEO Checklist (Copy-Paste Ready)

### Pre-Publish AEO Checklist

Every piece of content on uxintoax.com must pass these checks before publishing:

- [ ] Opens with a direct answer in the first 40–60 words (no preamble, no "In this article...")
- [ ] Primary question answered in the H1 or first H2
- [ ] At least one FAQ section with minimum 4 questions (FAQPage schema applied)
- [ ] All technical terms defined on first use ("Agent Experience (AX) is...")
- [ ] Each answer chunk is 40–60 words max per question
- [ ] No answer buried below the fold — key answers in first 300 words
- [ ] Headers written as complete questions where possible (e.g., "What is AX?" not "Definition")
- [ ] At least 2 internal links to pillar pages
- [ ] At least 1 external link to a credible source (research paper, major publication, official docs)
- [ ] Meta description written as a direct answer to the primary query
- [ ] Structured data validated (FAQPage + Article + BreadcrumbList) before publish
- [ ] Keyword appears in the first sentence of the first paragraph
- [ ] Image alt text includes target keyword
- [ ] URL slug is clean and keyword-rich (e.g., /blog/what-is-agent-experience)
- [ ] Content length matches intent: definition posts 800-1200w, pillar posts 2500-4000w

### The "AI Citation Test"

Before publishing, ask: **"If Perplexity searched for [primary keyword], would it pull a quote from this page?"**

If the answer is no — the opening answer block is not direct or concise enough. Rewrite it.

### AEO Content Rules

1. **No preamble.** Never start with "In this article..." or "Many people ask..." Just answer.
2. **One question, one answer block.** Keep them isolated. AI engines need extractable chunks.
3. **Define on first use.** First mention of "Agent Experience" → define it. First mention of "AX" → define it. First mention of "agentic AI" → define it.
4. **Headers as questions.** "What is AX?" ranks better for voice search than "Definition of AX."
5. **Internal anchor text.** Link pillar pages using exact-match keywords: "Learn more about [Agent Experience design]" not "Learn more here."
6. **Data = backlinks.** The /skills page with D3 charts should cite methodology, source URLs, and have a downloadable dataset. Data pages get linked by journalists, researchers, and universities.
